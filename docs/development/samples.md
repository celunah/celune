# Voice samples

This page is for listeners comparing Celune's current and historical voice demonstrations. It provides native audio players for every current voice and the archived voice recordings kept in `demos/`.

## Current recordings

The current set was generated on 30 September 2026 from the Classic Remastered pack (`voices/default.cevoice`). Each backend uses the same four voice identities, introduction text, and narration text. The recordings are 24-bit, 48 kHz mono FLAC files without playback DSP.

The players below are standard HTML audio controls. They load the repository-hosted recording directly and do not depend on an external player service. Use the fallback link inside a player to download its source file.

## Text and metadata

The current introduction and narration passages, reference voice hashes, model revisions, inference settings, output measurements, and recognition checks are recorded in [`demos/samples.json`](https://github.com/celunah/celune/blob/main/demos/samples.json). The filename convention is `{voice}_{length}_{backend}.{format}`, where `sc` is the short introduction and `lc` is the long narration.

The sample lines are intended to make pacing, consistency, and expressiveness easy to compare. Small pronunciation or prosody mistakes can remain because they are model outputs, not playback failures.

## Verification and limitations

If a player does not start, use its download link and open the file in a local media player. Modern browsers support the FLAC and WAV sources used here; browser codec support can vary by platform. The source files are served from the repository's `main` branch, so a future branch or repository rename requires updating the player URLs.

The recordings demonstrate voice cloning and backend output without Celune's playback pipeline, DSP, Persona, or agent runtime. They should not be treated as a benchmark of end-to-end runtime latency or final playback processing.
